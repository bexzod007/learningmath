Coefficients

1. The Core Idea: The Variable's Multiplier

Look at the expression 5x. The number 5 sitting right in front of the letter is called the coefficient.

Think of the coefficient as a count of how many identical variables you have added together:

5x = x + x + x + x + x

2. Key Rules for Coefficients

  • Negative Coefficients: In -3y, the coefficient is -3.
  • Fraction Coefficients: In ½x, the coefficient is ½.
  • Implicit Coefficients: In m, the coefficient is 1.

3. Summary & Definition

Definition: A coefficient is a number multiplied by a variable, positioned directly before the letter.
