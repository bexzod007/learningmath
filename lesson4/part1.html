What's variable?

1. The Core Idea: The Empty Box

Imagine you are packing for a trip and you have a cardboard box with a label on it that says "Age".

  • Right now, the box is empty.
  • You can put the number 14 inside it.
  • Next year, you take out 14 and put 15 inside the same box.
  • If your friend uses the box, they might put 16 inside it.

The box itself doesn't change, but the value inside the box changes. In math, instead of drawing cardboard boxes every time, we use a single letter like a or x. That letter is our variable!

2. Why Do We Need Variables?

Variables are super useful for three main reasons:

  1. To hold a place for an UNKNOWN number
    Imagine a mystery gift box: Box + $5 = $20.
    You don't know what is inside yet, but you know it must be $15.
    In algebra, we write: x + 5 = 20. The letter x holds the spot for the mystery number until we solve it.
  2. To describe a CHANGING amount
    Imagine you work at a bakery and make $10 per hour.
    How much money do you make? It depends on how many hours (h) you work!
    If you work 1 hour: 10 • 1 = $10.
    If you work 5 hours: 10 • 5 = $50.
    Here, h is a variable because the hours can change every single day.
  3. To write GENERAL rules for everyone
    Instead of writing: "To find next year's age, take 10 and add 1, or take 14 and add 1, or take 25 and add 1..."
    We write one single general rule for everyone on Earth: Next Year's Age = a + 1 (where a is your current age).

3. Real-World Examples

  • Example A: Mobile Data Plan
    Your phone plan gives you unlimited calls, but charges $2 for every extra Gigabyte (g) of internet you use.
    The extra cost is 2g.
    If you use 3 GB (g = 3), you pay 2 • 3 = $6.
    If you use 10 GB (g = 10), you pay 2 • 10 = $20.
    Variable: g (Gigabytes used).
  • Example B: Score in a Video Game
    In a game, every coin you collect gives you 100 points.
    Total points = 100c (where c is the number of coins).
    Collect 0 coins → 100 • 0 = 0 points.
    Collect 5 coins → 100 • 5 = 500 points.
    Variable: c (Number of coins collected).

4. Summary & Definition

Definition: A variable is a symbol (usually a letter like x, y, or a) that stands for a number. We use it when a number is unknown or when it changes (varies).

Teacher's Memory Trick: Think of the word Vary. "To vary" means "to change." So a vari-able is simply something that is able to change!
