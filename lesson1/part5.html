Absolute value

Understanding Absolute Value

The absolute value of a number represents its distance from zero on a number line, regardless of the direction. Because distance is always a positive quantity (or zero), absolute value is never negative.

In mathematics, we write absolute value using two vertical bars on either side of the number: | |

←   5 units to zero   —   0   —   5 units to zero   →
-5                            0                            5

Examples:

  • |5| = 5 → because 5 is 5 units away from zero.
  • |-5| = 5 → because -5 is also exactly 5 units away from zero.
  • |-10| = 10 → the negative sign is removed to measure pure distance.
  • |10| = 10 → positive numbers remain unchanged.

Real-World Analogy

Think of absolute value like walking a distance on a street:

  • If you walk 5 blocks East (positive direction), you walked 5 blocks.
  • If you walk 5 blocks West (negative direction), you still walked 5 blocks.

The total distance traveled is always positive, regardless of which direction you headed.

💡 Pro Tip: The magnitude rule!
You can think of absolute value as a "sign stripper"—it simply removes any negative sign and leaves the bare numerical size (magnitude) of the number.
