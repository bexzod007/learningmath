What is an Expression?

Exercise A: Basic Distribution

Expand each expression using the distributive property:

  1. 3(x + 5)
  2. 7(2y - 4)
  3. x(x + 8)

Exercise B: Distributing Negative Numbers

Carefully distribute the negative factor and simplify:

  1. -4(a + 6)
  2. -5(3b - 2)
  3. -2m(4m - 3)

Exercise C: Distribution & Combining Like Terms

Distribute first, then combine like terms to fully simplify:

  1. 4(2x + 3) + 5x
  2. 6(y - 2) - 3y
  3. -3(2a + 4) + 2(a - 1)
  4. 15 - 2(3x + 4)

Exercise A:

  1. 3(x) + 3(5) = 3x + 15
  2. 7(2y) - 7(4) = 14y - 28
  3. x(x) + x(8) = x² + 8x

Exercise B:

  1. -4(a) + (-4)(6) = -4a - 24
  2. -5(3b) - (-5)(2) = -15b + 10
  3. -2m(4m) - (-2m)(3) = -8m² + 6m

Exercise C:

  1. (8x + 12) + 5x = 13x + 12
  2. (6y - 12) - 3y = 3y - 12
  3. (-6a - 12) + (2a - 2) = -4a - 14
  4. 15 - 6x - 8 = -6x + 7
