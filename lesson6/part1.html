What is an Expression?

Exercise A: Identifying Like Terms

Group the following terms into sets of like terms:

5x, 3y, -2x, 8, 7y, 12

  1. Which terms belong to the x family?
  2. Which terms belong to the y family?
  3. Which terms are plain numbers (constants)?

Exercise B: Simplifying Basic Addition & Subtraction

Simplify each expression by combining like terms:

  1. 4a + 9a
  2. 15k - 6k
  3. 7m + 2m - 4m
  4. 12p - 5p - 3p

Exercise C: Simplifying Multiple Terms

Simplify each multi-term expression:

  1. 5x + 3 + 2x + 8
  2. 9a + 4b - 3a + 2b
  3. 6y + 10 - 2y - 4
  4. 8m + 5n - 3m - 2n + 7

Answer Key

🔍 Click here to reveal the Answers

Exercise A:

  • x family: 5x and -2x
  • y family: 3y and 7y
  • Constants: 8 and 12

Exercise B:

  1. (4 + 9)a = 13a
  2. (15 - 6)k = 9k
  3. (7 + 2 - 4)m = 5m
  4. (12 - 5 - 3)p = 4p

Exercise C:

  1. (5x + 2x) + (3 + 8) = 7x + 11
  2. (9a - 3a) + (4b + 2b) = 6a + 6b
  3. (6y - 2y) + (10 - 4) = 4y + 6
  4. (8m - 3m) + (5n - 2n) + 7 = 5m + 3n + 7
